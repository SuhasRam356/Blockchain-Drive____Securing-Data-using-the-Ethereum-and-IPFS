  • • Browser encrypts before upload
  • • IPFS stores encrypted blob
  • • Ethereum stores hash + access rules only (cheap)
  • • Sharing via encrypted key re-encryption
  • Result: Privacy + Ownership + Censorship resistance

11. STEGANOGRAPHY - Hide File Inside Image (Invisible Ink)

What?

  • • Encryption hides CONTENT, Stego hides EXISTENCE.
  • • Hide encrypted text inside image pixels - looks normal noise.
  • How (steganography.js):
  • • Toggle 'Use Steganography' ON upload
  • • encodeStego(null, ciphertext):
  • 1. Generate organic noise image Canvas random pixels 500x500
  • 2. Ciphertext → binary 0101...
  • 3. Inject binary into LSB Least Significant Bit of each pixel RGB
  • 4. LSB change invisible to human eye
  • 5. Export PNG upload PNG instead .enc
  • • Category auto #Stego tag to know decode
  • Why? IPFS viewer sees image not encrypted text doesn't suspect.
  • Extra layer over encryption even if know stego used still need AES key

Decode & Use:

  • Decode Flow:
  • • Download PNG IPFS
  • • Load Canvas read pixel data
  • • Extract LSBs → binary → ciphertext → decrypt
  • Limitations (honest viva):
  • • Image bigger than text overhead
  • • Small files optimal <1MB 1MB text needs ~2MB PNG
  • • Must keep PNG if JPEG LSB lost
  • Real Use:
  • • Journalists hiding documents
  • • Whistleblowers privacy users
  • Demo: Upload Stego ON → IPFS shows PNG noise image Open random but decodes works Impressive!
  • File: steganography.js encodeStego() decodeStego()
